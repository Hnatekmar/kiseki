# Logo

The mark is a pod outline with one corner missing, held together by a spark.
The tagline explains the rest.

| File | Use |
|---|---|
| `kiseki-mark.svg` | square mark, 512×512, for avatars and favicons |
| `kiseki-logo-light.svg` | horizontal lockup on light backgrounds |
| `kiseki-logo-dark.svg` | horizontal lockup on dark backgrounds |
| `kiseki-social.svg` | 1280×640 social card |
| `*.png` | 2× renders of the SVGs |

Palette: ink `#0B1220`, paper `#F8FAFC`, muted `#94A3B8`, amber `#FFD36E` → `#F59E0B`.
All text is converted to paths; the SVGs have no font dependency.
